# 임대지기 (RentKeeper)

임대인을 위한 임대현황·임대료·세금계산서 통합 관리 앱 프로토타입.

- `index.html` — 단일 파일 모바일 웹앱(PWA). 스마트폰 브라우저에서 바로 실행됩니다.
- `docs/임대지기_서비스기획서.docx` — 기능 명세, 상용 아키텍처, 로드맵, 법령 쟁점(부록 A).

## 실행
`index.html`을 브라우저로 열거나 정적 호스팅(GitHub Pages 등)에 올리면 됩니다.
AI 계약서 판독·파일 저장·클라우드 동기화는 claude.ai 아티팩트 뷰어에서 제공되는 런타임 기능이며,
단독 배포 시에는 직접 입력·브라우저 저장으로 동작합니다.
